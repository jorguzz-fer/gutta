# Fontes

Archivo Black (títulos) e Hind (texto), subconjunto latino (woff2), tiradas dos pacotes
`@fontsource/archivo-black` e `@fontsource/hind` 5.3.0 e servidas pelo próprio app. As duas
estão sob a SIL Open Font License 1.1 (https://openfontlicense.org), que permite redistribuir
junto com o software.

- Archivo Black: Copyright 2017 The Archivo Black Project Authors.
- Hind: Copyright (c) 2014 Indian Type Foundry.
